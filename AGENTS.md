# AGENTS.md

## Запуск и проверка
- Статический сайт (index.html + ES-модули в assets/js). Для работы нужен HTTP-сервер: `python3 -m http.server 5173 --bind 127.0.0.1`.
- Валидация данных: `python3 scripts/validate_data.py` (0 ошибок = OK).
- Данные лежат в `data/*.json`; словарь — `data/vocabulary.json` (Master Vocabulary).

## Пользовательский интерфейс
- Интерфейс не должен показывать технические детали: пути к файлам, JSON/JS/CSS, localStorage, API, внутренние ключи статусов (needs_review/verified/rejected).
- Внутренние ключи статусов в UI показывать только через человеческие подписи («Тексеру қажет», «Тексерілді», «Қабылданбады»).
- Ошибки пользователю — коротко и понятно; подробности только в консоли (console.warn/error).
- Сообщения на казахском (kk) с короткими русскими пояснениями.
- Платформа имеет ровно четыре направления: SPEAK, GAME, ҰЛТТЫҚ LAB, MEDIA SPACE. AI LAB и ЖИ-көмекші удалены из проекта — не добавлять их обратно.
- Пользовательские надписи «прогресс» заменять на «жетістік» (Менің жетістігім, Жалпы жетістік и т.д.).
