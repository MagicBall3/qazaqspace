# QAZAQ SPACE

Оқушыларға арналған қазақ тілін үйрену платформасы · Образовательная платформа для изучения казахского языка учениками 5–7 классов.

QAZAQ SPACE — не набор декоративных экранов, а рабочая учебная среда: уроки с проверкой, разговорная практика, игры, культурные карточки и творческая мастерская. Платформа включает четыре направления: SPEAK, GAME, ҰЛТТЫҚ LAB и MEDIA SPACE. Достижения считаются только по реальным действиям ученика и хранятся локально в браузере.

> **Статус материалов:** все языковые и культурные записи помечены `needs_review` — их должен проверить преподаватель.

---

## Быстрый старт

Нужен только Python 3. Node.js, сборка и установка зависимостей не требуются.

```powershell
cd "путь\к\проекту"
python scripts/serve.py
```

Откройте <http://127.0.0.1:5173>.

Можно и стандартным сервером:

```powershell
python -m http.server 5173
```

Важно: сайт **не работает через `file://`**, потому что использует ES-модули и `fetch` для JSON. Если открыть `index.html` двойным щелчком, появится предупреждение с инструкцией.

## Master Vocabulary и статусы

Единственный источник слов — `data/vocabulary.json`. У каждой записи есть:

- `id` — стабильный идентификатор (`word_001`);
- `kazakh`, `russian` — слово и перевод;
- `topic` — ссылка на тему из `topics`;
- `level` — 1, 2 или 3 (5, 6 или 7 класс);
- `partOfSpeech`, `exampleKz`, `exampleRu`, `notes`;
- `status` — `needs_review`, `verified` или `rejected`.

Значения статусов:

| Статус | Значение |
| --- | --- |
| `needs_review` | Черновая запись, требует проверки преподавателем. |
| `verified` | Преподаватель проверил слово, перевод и пример. |
| `rejected` | Запись отклонена и не должна использоваться в обучении. |

**Не ставьте `verified` без реальной проверки.** Интерфейс честно показывает статус и не выдаёт черновики за проверенный материал.

Подробная схема и порядок добавления данных — в [`docs/DATA_GUIDE.md`](docs/DATA_GUIDE.md).

## Достижения и приватность

- Достижения хранятся в `localStorage` под ключом `qazaqspace.v2`.
- Считаются только реальные события: завершённые уроки, ответы в играх, культурные задания, SPEAK-самопроверка и сохранённые работы.
- Баллы не начисляются за открытие страниц.
- «Меңгерілген сөз» — слово, по которому дано минимум два правильных ответа.
- Сброс достижений доступен на странице «Менің жетістігім» и требует подтверждения.
- Экспорт достижений скачивает JSON-файл.
- Творческие работы хранятся только на устройстве и не публикуются.
- Приложение не просит имя, телефон, адрес или e-mail. В MEDIA SPACE есть отдельное напоминание не писать личные данные.
- Старые достижения прототипа (`localStorage` ключ `qs`) переносится один раз; старые фиктивные баллы не переносятся.

Ограничение: достижения не синхронизируются между устройствами и браузерами. Для переноса используйте экспорт JSON.

## Проверка данных

Перед публикацией или после правок JSON:

```powershell
python scripts/validate_data.py
```

Скрипт проверяет:

- корректность JSON;
- уникальность ID;
- ссылки уроков на словарь;
- ссылки карточек на темы;
- индексы правильных ответов;
- допустимые уровни и статусы;
- наличие обязательных полей.

Код выхода `1` означает, что есть ошибки.

## Известные ограничения

- Озвучка зависит от наличия казахского голоса в браузере/системе. Если голоса нет, выводится предупреждение и предложение прочитать вслух.
- Материалы требуют методической и языковой проверки; культурные факты основаны на общеизвестных сведениях и имеют поле `source`.
- Достижения локальные, без аккаунтов и серверной синхронизации.
- Проект учебный; перед использованием в реальном классе проверьте данные и настройки приватности вашей школы.
