# QAZAQ SPACE — руководство по данным

Все учебные материалы хранятся в `data/*.json`. Интерфейс не содержит захардкоженных слов и вопросов, поэтому правки в данных сразу отражаются в уроках, играх, SPEAK, культуре и медиа.

Правила:

- кодировка файлов — **UTF-8 без BOM**;
- JSON не допускает комментариев и висячих запятых;
- идентификаторы (`id`) — латиница, цифры и `_`, без пробелов;
- после любых правок запускайте `python scripts/validate_data.py`;
- новые языковые записи получают статус `needs_review`;
- `verified` ставится только после реальной проверки преподавателем.

---

## 1. Общая схема

```text
data/vocabulary.json → слова и темы
        ↑
        ├── lessons.json      (уроки ссылаются на id слов)
        ├── speak.json        (диалоги и фразы)
        ├── games.json        (предложения, пословицы, викторина, квест)
        ├── culture.json      (культурные карточки и темы)
        └── media.json        (шаблоны творческих работ)
```

Связи:

- `lessons[].vocabulary[]` → `vocabulary.words[].id`;
- `vocabulary.words[].topic` → `vocabulary.topics[].id`;
- `culture.cards[].theme` → `culture.themes[].id`;
- `media.templates[].id` используется в достижениях сохранённых работ.

## 2. vocabulary.json — Master Vocabulary

```json
{
  "meta": { "version": "1.0.0", "note": "…" },
  "topics": [
    { "id": "greetings", "kz": "Сәлемдесу", "ru": "Приветствия" }
  ],
  "words": [
    {
      "id": "word_001",
      "kazakh": "сәлем",
      "russian": "привет",
      "topic": "greetings",
      "level": 1,
      "partOfSpeech": "зат есім",
      "exampleKz": "Сәлем, менің атым Айгүл.",
      "exampleRu": "Привет, меня зовут Айгуль.",
      "notes": "Неформальное приветствие",
      "status": "needs_review"
    }
  ]
}
```

| Поле | Обязательное | Описание |
| --- | --- | --- |
| `id` | да | Уникальный ID, например `word_109`. |
| `kazakh` | да | Слово на казахском. |
| `russian` | да | Перевод на русский. |
| `topic` | да | ID темы из `topics`. |
| `level` | да | `1` — 5 класс, `2` — 6 класс, `3` — 7 класс. |
| `partOfSpeech` | нет | Часть речи. |
| `exampleKz` | да | Пример на казахском. |
| `exampleRu` | да | Перевод примера. |
| `notes` | нет | Комментарий для учителя. |
| `status` | да | `needs_review`, `verified`, `rejected`. |

Статусы:

- `needs_review` — черновик;
- `verified` — проверено преподавателем;
- `rejected` — отклонено, не использовать.

### Как добавить слово

1. Откройте `data/vocabulary.json`.
2. Найдите максимальный `word_NNN` и возьмите следующий номер.
3. Добавьте объект в конец массива `words`.
4. Укажите существующую тему или добавьте новую в `topics`.
5. Поставьте `"status": "needs_review"`.
6. Запустите валидатор.

## 3. lessons.json — уроки

```json
{
  "id": "lesson_greetings",
  "level": 1,
  "titleKz": "Танысу",
  "titleRu": "Знакомство",
  "summary": "Сәлемдесу, өзіңді таныстыру және қоштасу.",
  "goal": "Үйренуші сәлемдесе алады…",
  "vocabulary": ["word_001", "word_002"],
  "examples": [
    { "kz": "Сәлем! Менің атым Дана.", "ru": "Привет! Меня зовут Дана." }
  ],
  "explanation": [
    { "title": "Сәлемдесу уақыты", "body": "Қайырлы таң — доброе утро…" }
  ],
  "practice": {
    "questions": [
      {
        "prompt": "«Сәлеметсіз бе» деген не?",
        "options": ["Здравствуйте", "До свидания", "Спасибо"],
        "answer": 0,
        "explain": "Вежливое приветствие."
      }
    ],
    "openTask": {
      "prompt": "Өзіңді таныстыр: 3 сөйлем жаса.",
      "hints": ["Менің атым …", "Сау болыңыз!"],
      "modelAnswer": "Қайырлы күн! Менің атым Аслан."
    }
  }
}
```

Требования:

- `level` — 1, 2 или 3;
- в `vocabulary` — только существующие ID слов;
- минимум 3 вопроса в `practice.questions`;
- `answer` — индекс правильного варианта, начиная с 0;
- `practice.openTask.prompt` обязателен;
- для каждого уровня должен быть хотя бы один урок.

Проверочный квиз засчитывает урок при результате **≥ 75%**.

## 4. speak.json — диалоги и ролевые ситуации

```json
{
  "id": "speak_meeting",
  "level": 1,
  "titleKz": "Танысу",
  "titleRu": "Знакомство",
  "situationRu": "Ты пришёл в новый кружок…",
  "goal": "Поздороваться, назвать имя…",
  "dialogue": [
    {
      "speaker": "Айгүл",
      "side": "a",
      "kz": "Сәлем! Менің атым Айгүл.",
      "ru": "Привет! Меня зовут Айгуль."
    }
  ],
  "phrases": [
    { "kz": "Менің атым …", "ru": "Меня зовут …" }
  ],
  "rolePlay": {
    "yourRole": "Жаңа оқушы",
    "partnerRole": "Сыныптасы",
    "task": "Сыныптасыңмен таныс.",
    "steps": ["Сәлемдес.", "Атыңды айт."]
  },
  "selfCheck": ["Мен сәлемдесе алдым."],
  "teacherNote": "Парная работа…"
}
```

- `side`: `a` — слева, `b` — справа;
- минимум 3 реплики;
- `selfCheck` — пункты самопроверки, не автопроверка;
- `teacherNote` не показывается ученику, но полезен методисту (сейчас хранится в данных).

## 5. games.json

### sentences — порядок слов

```json
{ "id": "sent_01", "words": ["Мен", "мектепке", "барамын"], "ru": "Я иду в школу.", "level": 1 }
```

`words` — правильный порядок. Игра перемешивает токены.

### proverbs — пословицы

```json
{
  "id": "prov_01",
  "beginning": "Бірлік болмай,",
  "options": ["тірлік болмайды.", "жол ұзақ болады.", "күн жылы болады."],
  "answer": 0,
  "ru": "Без единства нет жизни.",
  "meaning": "Бірлік — отбасы мен қоғамның негізі.",
  "status": "needs_review"
}
```

### quiz — викторина

```json
{
  "id": "q_01",
  "level": 1,
  "question": "Қазақ әліпбиінде неше әріп бар?",
  "options": ["42", "33", "26"],
  "answer": 0,
  "explain": "Қазақ кирилл әліпбиінде 42 әріп бар."
}
```

### quest — QR-квест

```json
{
  "titleKz": "Мәдениет іздері",
  "titleRu": "Следы культуры",
  "introRu": "…",
  "noteRu": "…",
  "stations": [
    {
      "id": "station_01",
      "titleKz": "Дастарқан",
      "titleRu": "Дастархан",
      "code": "QAZAQ-1",
      "taskKz": "…",
      "question": "Қазақтың дәстүрлі сусыны қайсы?",
      "options": ["Қымыз", "Кола", "Апельсин шырыны"],
      "answer": 0,
      "explain": "Қымыз — бие сүтінен жасалатын дәстүрлі сусын.",
      "hint": "Ол бие сүтінен жасалады."
    }
  ]
}
```

Требования:

- коды станций уникальны;
- `answer` — индекс верного варианта;
- при изменении кодов обновите `docs/TEACHER_GUIDE.md`.

## 6. culture.json

```json
{
  "themes": [
    { "id": "food", "kz": "Ұлттық тағамдар", "ru": "Национальные блюда" }
  ],
  "cards": [
    {
      "id": "culture_beshbarmak",
      "theme": "food",
      "level": 2,
      "titleKz": "Бешбармақ",
      "titleRu": "Бешбармак",
      "textKz": "Бешбармақ — қазақтың дәстүрлі тағамы…",
      "textRu": "Бешбармак — традиционное казахское блюдо…",
      "dictionary": [
        { "kz": "ет", "ru": "мясо" },
        { "kz": "қамыр", "ru": "тесто" }
      ],
      "task": {
        "question": "Бешбармақ қандай өнімдерден дайындалады?",
        "options": ["Ет пен қамырдан", "Балық пен күріштен", "Сүт пен жидектен"],
        "answer": 0,
        "explain": "Негізгі құрам — ет және қамыр."
      },
      "status": "needs_review",
      "source": "Жалпыға белгілі мәдени дерек"
    }
  ]
}
```

Правила:

- `theme` должен существовать в `themes`;
- `source` обязателен: укажите учебник, официальный источник или пометку «общеизвестные сведения»;
- не добавляйте спорные даты и факты без проверки;
- `status` — как у словаря.

## 7. media.json

```json
{
  "id": "media_my_school",
  "type": "text",
  "level": 1,
  "titleKz": "Менің мектебім",
  "titleRu": "Моя школа",
  "brief": "Мектебің туралы қысқа әңгіме жаз.",
  "prompt": "Мектебің қандай? 4–6 сөйлем жаз.",
  "starters": ["Менің мектебім …", "Маған мектепте … ұнайды."],
  "checklist": ["Мектептің атауы аталды", "Кемінде бір «Маған … ұнайды» сөйлемі бар"],
  "minSentences": 4
}
```

- `type`: `text`, `interview`, `news`, `podcast`, `report`, `script`;
- `minSentences` используется для счётчика предложений и статуса «Жеткілікті/Жеткіліксіз»;
- `checklist` — самопроверка, не автоматическая оценка;
- работы учеников в JSON не записываются: они хранятся в `localStorage`.

## 8. Типичные ошибки

| Ошибка | Что происходит | Как исправить |
| --- | --- | --- |
| Висячая запятая | JSON не парсится, экран ошибки | Удалите запятую перед `}` или `]`. |
| `answer: 3` при 3 вариантах | Неверный индекс | Индексы начинаются с 0: `0..2`. |
| Ссылка на несуществующий `word_999` | Ошибка в уроке | Добавьте слово или исправьте ID. |
| Дубликат `id` | Валидатор сообщает об ошибке | Сделайте ID уникальным. |
| `verified` без проверки | Нарушение методических правил | Верните `needs_review`. |
| Файл сохранён в Windows-1251 | Кракозябры в интерфейсе | Пересохраните в UTF-8. |
| Правки не видны | Кеш браузера | Используйте `scripts/serve.py` и обновите страницу. |

## 9. Проверка и публикация

```powershell
python scripts/validate_data.py
python scripts/serve.py
```

Валидатор проверяет не только синтаксис, но и связи между разделами. Перед публикацией убедитесь, что:

- ошибок нет;
- все новые записи имеют `needs_review`;
- коды квеста совпадают с руководством учителя;
- в репозиторий не попали `.secrets/`, `.env` и ключи API.

Секреты и токены храните только вне Git. В проекте для этого уже настроен `.gitignore`.
