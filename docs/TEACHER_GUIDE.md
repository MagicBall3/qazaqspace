# QAZAQ SPACE — руководство для учителя

Платформа предназначена для учеников 5–7 классов. Интерфейс в основном на казахском языке, пояснения и подсказки — на русском. Все материалы имеют статус `needs_review` до проверки преподавателем.

---

## 1. Перед первым занятием

1. Запустите сайт локально:

   ```powershell
   python scripts/serve.py
   ```

   Откройте <http://127.0.0.1:5173>. Не открывайте `index.html` через `file://` — модули и JSON не загрузятся.

2. Проверьте данные:

   ```powershell
   python scripts/validate_data.py
   ```

3. Пройдите сами один урок и одну игру, чтобы увидеть интерфейс и обратную связь.

4. Решите, как ученики будут работать:
   - каждый на своём устройстве — прогресс сохраняется в его браузере;
   - на одном общем компьютере — предупредите, что прогресс общий, и используйте сброс между учениками;
   - без сохранения — можно проходить игры и уроки, но прогресс не перенесётся.

## 2. Уровни и материалы

| Уровень | Класс | Акцент |
| --- | --- | --- |
| 1 | 5 класс | Приветствие, семья, простые фразы, базовые слова. |
| 2 | 6 класс | Школа, магазин, направление, короткий диалог. |
| 3 | 7 класс | Город, мнение, аргументация, развёрнутый ответ. |

### Уроки

| ID | Урок | Класс |
| --- | --- | --- |
| `lesson_greetings` | Танысу / Знакомство | 5 |
| `lesson_family` | Менің отбасым / Моя семья | 5 |
| `lesson_school` | Мектепте / В школе | 6 |
| `lesson_shop` | Дүкенде / В магазине | 6 |
| `lesson_city` | Қалада бағыт сұрау / Как спросить дорогу | 7 |
| `lesson_opinion` | Пікір білдіру / Выражение мнения | 7 |

Структура каждого урока: цель → новые слова → примеры → объяснение → творческое задание → проверочный квиз → результат.

Урок засчитывается при **не менее 75% правильных ответов**. Ученик может пройти квиз повторно; в прогрессе сохраняется лучший результат.

### SPEAK

7 сценариев: знакомство, школа, магазин, библиотека, семья, любимое занятие, дорога в городе.

Методика:

1. Ученик читает диалог и слушает отдельные реплики (кнопка динамика).
2. Скрывает перевод и пытается понять смысл.
3. Читает вслух по ролям с партнёром.
4. Выполняет ролевую задачу.
5. Отмечает пункты самопроверки и завершает сценарий.

Самопроверка — это не автоматическая оценка. Учитель может пройтись по классу и послушать пары.

### GAME

| Игра | Навык | Правила |
| --- | --- | --- |
| Сөзді тап | Словарь | 5 раундов, выбор перевода, +5 за верный ответ. |
| Сөйлем құрастыр | Порядок слов | 4 предложения, +10 за верное. |
| Жұпты тап | Словарь | 8 пар, +10 за пару, −2 за ошибку. |
| Мақалды жалғастыр | Пословицы | 6 пословиц, +10 за верный вариант. |
| Викторина | Язык и культура | 10 вопросов, +10 за верный, с объяснением. |
| QR-квест | Культура | 5 станций, 10 баллов + 5 бонус за код. |
| Тіл марафоны | Скорость и точность | 90 секунд, 12 вопросов, +5 за верный. |

Игры можно использовать как разминку (5 минут), закрепление или индивидуальную траекторию. Результаты сохраняются локально и видны в разделе «Менің прогресім».

### ҰЛТТЫҚ LAB

14 карточек по 7 темам: национальные блюда, традиции, игры, история, пословицы, личности, праздники.

Каждая карточка содержит:

- текст на казахском;
- пояснение на русском;
- мини-словарь;
- задание с одним верным вариантом;
- поле `source` — основание для сведений.

Карточка засчитывается после верного ответа. Культурные факты намеренно даны как общеизвестные; перед уроком сверьте даты, имена и термины с учебником и утверждёнными источниками.

### MEDIA SPACE

11 шаблонов, включая обязательные:

- «Менің мектебім»;
- «Менің сүйікті пәнім»;
- «Менің қалам — Астана»;
- «Ұлттық тағамдар»;
- «Ұстазға үш сұрақ».

Ученик выбирает шаблон, пишет текст, при необходимости вставляет готовые начала фраз, отмечает чек-лист и сохраняет работу. Работа остаётся на устройстве; её можно скачать как `.txt`.

Рекомендации:

- 5–7 предложений для 5 класса, 6–8 для 6–7 класса;
- обязательный элемент — личное мнение или объяснение причины;
- перед сохранением проверьте, нет ли телефона, адреса и других личных данных.

## 3. QR-квест: подготовка

Коды станций (не публикуйте их в открытом чате класса, если хотите сохранить элемент поиска):

| Станция | Тема | Код |
| --- | --- | --- |
| 1 | Дастарқан | `QAZAQ-1` |
| 2 | Домбыра | `QAZAQ-2` |
| 3 | Наурыз | `QAZAQ-3` |
| 4 | Ұлттық ойын | `QAZAQ-4` |
| 5 | Тәуелсіздік | `QAZAQ-5` |

Как подготовить:

1. Сгенерируйте QR-код в любом школьном генераторе: в содержимое достаточно вписать только код, например `QAZAQ-1`.
2. Распечатайте коды и разместите их в кабинете или коридоре.
3. Ученик открывает игру «QR-квест», выбирает станцию, при необходимости вводит код и отвечает на вопрос.
4. Без кода станция тоже засчитывается, но бонус +5 не начисляется — это честно показано в интерфейсе.

Квест считается завершённым после всех пяти станций. Результат сохраняется в прогрессе.

## 4. Проверка языковых материалов

Статусы:

- `needs_review` — черновик, использовать можно только как учебный черновик;
- `verified` — преподаватель реально проверил слово, перевод и пример;
- `rejected` — запись отклонена.

Порядок проверки:

1. Откройте `data/vocabulary.json` и найдите запись.
2. Сверьте перевод, пример, часть речи и уровень с учебником.
3. Исправьте текст или пример.
4. Только после проверки замените `needs_review` на `verified`.
5. Запустите `python scripts/validate_data.py`.

Не ставьте `verified` массово «для красоты»: интерфейс показывает статус ученику и учителю.

Подробная схема полей — в [`DATA_GUIDE.md`](DATA_GUIDE.md).

## 5. Оценивание

Платформа даёт формирующую обратную связь, а не автоматическую итоговую оценку.

Что можно использовать:

- процент завершённых уроков;
- лучшие результаты игр;
- количество слов, по которым дано минимум два верных ответа («меңгерілген сөз»);
- завершённые культурные карточки;
- сохранённые творческие работы;
- устную проверку SPEAK-диалогов.

Что не стоит делать:

- приравнивать баллы игр к четвертной оценке;
- считать открытие страницы учебной активностью — платформа этого не делает;
- сравнивать учеников только по очкам: набор заданий случайно перемешивается.

Пример критериев для творческой работы:

| Критерий | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Объём | меньше 3 предложений | 3–4 | 5 и больше |
| Содержание | не по теме | частично | полностью по теме |
| Язык | много ошибок, мешает пониманию | ошибки есть, смысл понятен | ошибки единичны |
| Мнение/причина | отсутствует | намёк | ясно выражено |

## 6. Приватность и безопасность

- Нет регистрации, аккаунтов и серверной отправки прогресса.
- Прогресс и работы хранятся в `localStorage` браузера.
- AI LAB по умолчанию не отправляет текст в интернет.
- При подключении реального ИИ используйте только серверный прокси; ключи хранятся в переменных окружения на сервере.
- Попросите учеников не писать в MEDIA SPACE и AI LAB телефон, адрес, пароли и другие личные данные.
- На общем компьютере сбрасывайте прогресс после ученика: «Менің прогресім» → «Прогресті сброс ету». Перед сбросом можно скачать JSON-экспорт.

## 7. Типичные проблемы

| Симптом | Причина | Решение |
| --- | --- | --- |
| Пустой экран, предупреждение про `file://` | Сайт открыт двойным щелчком | Запустите `python scripts/serve.py` |
| «Деректер қатесі» | Повреждён JSON или битая ссылка | Запустите `python scripts/validate_data.py` |
| Нет звука | В системе нет казахского голоса | Прочитайте текст вслух; озвучка не обязательна |
| Прогресс не сохраняется | Приватный режим или запрет localStorage | Разрешите хранение данных для сайта |
| AI отвечает шаблонами | Включён демо-режим | Это ожидаемо; см. README для подключения сервера |
| После правки JSON ничего не изменилось | Кеш браузера | Перезагрузите страницу; используйте `scripts/serve.py` |

## 8. Готовый план урока на 45 минут

**Тема: Танысу (5 класс)**

1. 0–5 мин — слово дня на главной странице, проговаривание.
2. 5–15 мин — урок `lesson_greetings`: слова и примеры, чтение вслух.
3. 15–25 мин — SPEAK `speak_meeting`: диалог по ролям в парах.
4. 25–35 мин — игра «Сөзді тап» или «Жұпты тап».
5. 35–42 мин — проверочный квиз урока, разбор ошибок.
6. 42–45 мин — рефлексия: что запомнилось, какое слово было самым трудным.

Домашнее задание: MEDIA SPACE «Менің мектебім» — 4–6 предложений.
